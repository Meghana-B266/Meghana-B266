### 🧠 Research Paper Knowledge Graph Explorer

[![Repo](https://img.shields.io/badge/Explore_Repository-181717?style=flat&logo=github)](https://github.com/Meghana-B266/research-kg-explorer)

### 🌊 Floating Plastic Detection

[![Repo](https://img.shields.io/badge/Explore_Repository-181717?style=flat&logo=github)](https://github.com/Meghana-B266/waste_detection)

A deep learning-based system for detecting and tracking floating plastic pollution in riverine environments.

**Key Features**
- Uses YOLOv11n for real-time plastic detection.
- Integrates ByteTrack for multi-object tracking.
- Processes IP camera streams at approximately 15 FPS on CPU.
- Sends email alerts with annotated detection images.
- Stores detection events in SQLite for historical analysis.

**Reported Results**
- 98.8% mAP@50
- 95% F1-score
- Custom dataset containing 2,200+ plastic instances

**Tech Stack**

`Python` `YOLOv11n` `ByteTrack` `OpenCV` `FastAPI` `SQLite`
